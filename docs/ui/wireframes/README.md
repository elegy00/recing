# Wireframes

Low-fidelity layout diagrams for the Recing application. Organized into two concerns:

- **[Layout](./layout/)** — Structural elements shared across all pages (header, navigation, content area, footer, spacing/sizing)
- **[Content](./content/)** — Page-specific views and their states (submit, recipe detail, error, list/history, loading overlay)

The sitemap was merged into this structure — page definitions live in `content/` alongside the layout system they use.
