# Design Inspiration

This folder contains reference images and inspiration sources for the hi-fi design.

## Purpose

Collect visual references that inform:
- Color palette decisions
- Typography choices
- Layout patterns
- Component styling
- Overall visual direction

## Usage

1. Add reference images with descriptive filenames
2. Document what aspect of each image is relevant (color, layout, interaction, etc.)
3. Note specific elements to incorporate or avoid
